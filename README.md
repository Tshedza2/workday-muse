# Lovable AI Build Prompt: AI Workplace Productivity Assistant

Build a modern, responsive SaaS web application called **AI Workplace Productivity Assistant** that helps professionals improve productivity using AI.

### 1. Design and Layout
- Use a clean, professional **purple-and-white** colour scheme with light grey backgrounds, modern typography, rounded cards, and subtle shadows.
- Create a dashboard with a left sidebar, top navigation, and a spacious main content area.
- Ensure the interface is responsive on desktop, tablet, and mobile.
- Avoid generic AI templates; make the design polished and consistent.

### 2. Core Features

**A. Smart Email Generator**
- Generate professional emails based on the user's instructions, purpose, and recipient.
- Support Formal, Friendly, and Persuasive tones.
- Allow users to edit, regenerate, and copy generated emails.

**B. AI Research Assistant**
- Accept research topics, pasted articles, and website URLs.
- Summarise provided content and identify key points, insights, and recommendations.
- Clearly indicate when URL content cannot be accessed.

**C. AI Chatbot**
- Provide an interactive workplace assistant that responds contextually to user prompts.
- Support brainstorming, writing, explanations, and workplace problem-solving.
- Maintain relevant context during the current conversation.

### 3. AI Behaviour
- Generate relevant, specific, context-aware responses based on user input rather than generic templates.
- Use structured prompts for each tool.
- Include loading indicators, clear error messages, and editable outputs.
- Add a responsible AI disclaimer reminding users to verify important information.

### 4. Technical Requirements
- Build a **frontend-only application** with no backend, database, authentication, login, or registration.
- Use client-side state for temporary interactions; do not permanently store user data.
- Do not use mock AI responses or pretend that AI processing is real.
- If live AI generation requires an API or backend, clearly explain the limitation and provide a simple integration-ready interface without creating a backend.

### 5. Final Instructions
Build the complete, functional frontend with all three features accessible through the sidebar. Prioritise usability, clean navigation, working buttons, editable results, and a consistent purple-and-white design. Keep the implementation simple and suitable for a beginner to understand and maintain.
